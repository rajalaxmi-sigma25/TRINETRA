# 🔍 Trinetra – Criminal Record Management System

## 📌 About the Project

Trinetra is a **Software Engineering academic project** developed as part of my college coursework.

It is a web-based Criminal Record Management System designed to organize, store, and manage criminal record information through a user-friendly interface.

The project explores how technology can help make record management more structured and efficient.

## 🎯 Objectives

- Organize criminal record information.
- Provide an easy-to-use management interface.
- Make record access and management more convenient.
- Understand real-world software development concepts.

## ✨ Features

- User-friendly interface
- Criminal record management
- Organized information display
- Responsive web design

## 🛠️ Technologies Used

- HTML
- CSS
- TypeScript

## 🤖 AI-Assisted Development

This project was developed with the assistance of AI tools for guidance, coding support, and development ideas. The project design, implementation, and development process were carried out as part of my academic learning.
