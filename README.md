## 📌 About the Project

TRINETRA is a web-based Criminal Record Management System designed to store, organize, and manage criminal record information digitally.

The system aims to provide an organized platform where authorized users, such as Police Officers and CBI Officers, can manage and access criminal record information efficiently.

This project is developed as part of an academic Software Engineering practical to understand the software development process, system design, implementation, and project management.

## 🎯 Project Objectives

- To maintain criminal records in an organized digital format.
- To reduce manual record-keeping.
- To provide easy access to stored criminal information for authorized users.
- To improve the organization and management of criminal records.
- To develop a user-friendly web-based management system.

## ✨ Key Features

- **Digital Record Management:** Organized storage and management of criminal information.
- **User Authentication:** Login interface for accessing the system.
- **Role-Based Access:** Different user roles for police and CBI officers.
- **Record Management:** Interface for managing criminal records.
- **Dashboard:** Organized interface for accessing system information.
- **User-Friendly Interface:** Simple and accessible web-based design.

## 🛠️ Technologies Used

- **HTML5** – Structure of the web application.
- **CSS3** – Styling and layout.
- **TypeScript** – Application logic and functionality.
- **React.js** – Frontend user interface.
- **Tailwind CSS** – Responsive styling.
- **Vite** – Development and build tool.
- **Git & GitHub** – Version control and project hosting.
